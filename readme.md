# Spotify Listening Analysis 🎵

A mini-project to dive deeper into my Spotify listening habits, inspired by the annual Spotify Wrapped but with a more personalized approach.

## 📖 Overview 
This project analyzes my personal Spotify streaming history to uncover patterns and insights beyond what's provided by Spotify's yearly summary. It focuses on:
- Top artists and tracks
- Listening patterns (time/day analysis)


## ✨ Features
- **Listening Patterns**: Visualize when and how often I listen to music
- **Duration Analysis**: Distribution of track lengths I prefer
- **JSON Export**: Raw listening data in structured format
